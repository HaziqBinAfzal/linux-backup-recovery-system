# Linux Backup and Recovery System

This project demonstrates a secure backup and recovery workflow implemented across Linux systems.

The process is documented using screenshots showing each stage from backup creation to recovery.

## Workflow Overview

1. Backup execution using rsync  
2. Data compression using tar  
3. Encryption using GPG  
4. Integrity verification using SHA256  
5. Secure transfer via SSH  
6. Automated scheduling using cron  
7. Recovery and restoration testing  

## Screenshots

The screenshots in this repository show the full lifecycle of the system:
- Backup process

- SSH transfer
- Checksum verification
- Cron automation
- Recovery process

## Tools Used
Linux, rsync, SSH, GPG, tar, cron, SHA256
